## 📚 عن المشروع (EduCamp)
منصة متكاملة مصممة لمساعدة الطلاب والمستقلين على تنظيم جداولهم الدراسية، إدارة المهام اليومية، وتتبع الإنتاجية بكل سهولة وفعالية.

### ✨ الميزات الرئيسية
* تنظيم المهام والجداول الدراسية.
* واجهة مستخدم سلسة ومرنة.
* تتبع التقدم والمهام المنجزة.

## 📚 About EduCamp
An integrated platform designed to help students and individuals organize their study schedules, manage daily tasks, and track productivity with ease and efficiency.

### ✨ Key Features
* Task and study schedule organization.
* Smooth and flexible user interface.
* Progress and completed task tracking.
